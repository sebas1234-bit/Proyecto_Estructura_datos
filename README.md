# Proyecto_Estructura_datos
Proyecto Integrador Estructura Datos


Funcionalidades principales

* Registro de películas.
* Gestión de salas de cine.
* Visualización de la disponibilidad de asientos.
* Compra y cancelación de entradas.
* Administración de la fila de clientes.
* Consulta del historial de operaciones.
* Búsqueda rápida de películas o clientes.

Este proyecto tiene un enfoque completamente educativo y busca demostrar la aplicación práctica de las principales estructuras de datos vistas durante el curso.
