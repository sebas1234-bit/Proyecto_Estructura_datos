# 🎬 Cine Santa Fe

## Descripción

Durante años, el cine de Santa Fe ha sido un punto de encuentro para el pueblo, pero su crecimiento ha generado problemas de administración: registros manuales, confusión con los asientos, largas filas, reservas duplicadas y pérdida de información.

Por esto nace Cine Santa Fe, una plataforma que centraliza la gestión de películas, salas, funciones, clientes y entradas, permitiendo consultar la cartelera, elegir asientos y realizar compras de forma sencilla y organizada.

### 🎟️ Aquí entra Cine Santa Fe

Cine Santa Fe es una plataforma que moderniza la administración del cine, permitiendo gestionar películas, salas, funciones, clientes y entradas desde un solo lugar.

Además, facilita la experiencia del usuario al consultar la cartelera, elegir asientos y realizar compras. El sistema utiliza diferentes estructuras de datos para organizar la información, gestionar asientos, filas de espera, operaciones y búsquedas.

Así, el cine se convierte en un sistema más organizado, dinámico y eficiente para todo el pueblo.

---

## 🎯 ¿Qué ofrece el sistema?

Cine Santa Fe busca centralizar las operaciones principales del cine y facilitar tanto la experiencia de los clientes como el trabajo del personal.

Entre sus principales funcionalidades se encuentran:

**Gestión de películas** y catálogo disponible.
**Administración de salas** y sus respectivos asientos.
**Visualización de disponibilidad de asientos** en cada función.
**Compra y cancelación de entradas.**
**Sala de espera virtual** para funciones con alta demanda.
**Actualización de asientos en tiempo real** entre los usuarios conectados.
**Deshacer operaciones recientes** desde el panel del personal.
**Consulta del historial de funciones y ventas.**
**Búsqueda rápida** de películas y clientes.
**Recomendación de películas** basadas en características como género, categoría o elementos compartidos con otras películas.

---

## 🧩 Las estructuras detrás del cine

Las estructuras de datos no están presentes únicamente como elementos teóricos. Cada una se utiliza para resolver una necesidad concreta dentro de Cine Santa Fe.

| Estructura                       | Uso dentro de Cine Santa Fe                                                                        |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Vectores**                     | Organización del catálogo de películas disponibles.                                                |
| **Matrices**                     | Representación de los asientos de cada sala y su estado: disponible, reservado u ocupado.          |
| **Colas (FIFO)**                 | Administración de la sala de espera virtual cuando una función tiene mucha demanda.                |
| **Pilas (LIFO)**                 | Registro de operaciones recientes y funcionamiento de la opción para deshacer la última operación. |
| **Listas enlazadas simples**     | Organización de las entradas asociadas a cada cliente.                                             |
| **Listas enlazadas dobles**      | Navegación por el historial de funciones y ventas hacia adelante y hacia atrás.                    |
| **Árboles binarios de búsqueda** | Búsqueda eficiente de películas y clientes mediante códigos identificadores.                       |

## Recomendaciones para los amantes del cine

Cine Santa Fe no solo busca ayudar a los clientes a encontrar una película: también quiere ayudarles a **descubrir qué ver después**.
A partir de la información disponible en el catálogo, el sistema puede encontrar películas que compartan determinadas características, como:

* Género.
* Categoría.
* Actores.
* Director.
* Año o periodo de lanzamiento.

Por ejemplo, si un cliente está consultando una película de acción, el sistema puede recorrer el catálogo y encontrar otras películas que compartan ese género u otras características relevantes.

---

## 🎥 ¿Por qué Cine Santa Fe?

Porque administrar un cine no debería sentirse como administrar un caos.

Detrás de cada película, cada cliente, cada asiento y cada entrada existe información que debe organizarse correctamente.

**Cine Santa Fe convierte esa complejidad en un sistema organizado**, utilizando estructuras de datos y herramientas de desarrollo modernas para construir una experiencia más sencilla tanto para quienes disfrutan de una película como para quienes hacen posible que el cine funcione.

> *Una película comienza cuando se apagan las luces.*
> *Una buena experiencia comienza mucho antes.* 🍿
